BandaNV v1.0

LANZAMIENTO ESTABLE — BANDA NV v1.0

NOVEDAD PRINCIPAL
BandaNV incorpora un sistema de actualización portable basado exclusivamente en GitHub Releases.

CONFIGURACIÓN INICIAL
- En una instalación nueva, BandaNV guía al usuario para elegir la carpeta que desea organizar.
- Mientras no haya una carpeta válida, ORGANIZAR permanece deshabilitado.
- El botón Configuración se destaca temporalmente como CONFIGURAR CARPETA.
- El aviso inicial se muestra una sola vez; la guía visual permanece hasta configurar una carpeta válida.

ACTUALIZACIONES
- GitHub Releases es la fuente oficial de versiones.
- El canal de actualizaciones ya no depende de si la build instalada es RC o Final.
- Cada usuario puede elegir si quiere recibir también Pre-releases desde Configuración.
- "Buscar actualizaciones al iniciar" está activado por defecto y puede desactivarse desde Configuración.
- "Comprobar si hay versiones beta disponibles" está desactivado por defecto.
- Con beta desactivada, BandaNV consulta únicamente la Latest Release estable.
- Con beta activada, BandaNV compara Releases estables y Pre-releases y ofrece la versión válida más nueva.
- Desactivar beta nunca provoca un downgrade a una versión estable anterior.
- El chequeo automático es silencioso cuando no hay novedades o GitHub no responde.
- El botón BUSCAR ACTUALIZACIONES utiliza el canal seleccionado en Configuración.
- Configuración muestra la fecha y hora de la última comprobación exitosa.
- La última comprobación se conserva entre ejecuciones.
- Si GitHub no responde, la fecha anterior no se reemplaza.

PAQUETES
- BandaNV_vX.Y_Portable.zip
  Descarga manual para una instalación nueva.

- BandaNV_vX.Y_AutoUpdate.zip
  Paquete exclusivo del actualizador automático.

BandaNV nunca usa Portable.zip como reemplazo de AutoUpdate.zip.

NVUPDATE
- NVupdate.exe es el helper permanente del actualizador.
- Espera a que BandaNV.exe cierre antes de reemplazarlo.
- Crea un backup del ejecutable anterior.
- Inicia la versión nueva con un token único de confirmación.
- El backup se elimina solo después de que la nueva BandaNV muestra correctamente su ventana principal.
- Si la nueva versión no confirma el arranque, se restaura automáticamente la versión anterior.

SEGURIDAD E INTEGRIDAD
- AutoUpdate.zip debe provenir de la Release detectada en el repositorio oficial.
- BandaNV exige el SHA-256 publicado por GitHub en assets[].digest.
- Si el hash falta o no coincide, la instalación se cancela.
- El ZIP se valida antes de ejecutar NVupdate.
- BandaNV.exe debe estar en la raíz del AutoUpdate.zip.
- config\ y logs\ nunca se reemplazan.
- Se rechazan rutas inseguras dentro del ZIP.
- Un ZIP corrupto o inválido se rechaza antes de tocar la instalación.
- Si falta NVupdate.exe, BandaNV permanece abierta y no modifica el ejecutable actual.

ROLLBACK
- Una actualización que no confirma un arranque correcto activa rollback.
- La Release que provocó el rollback queda registrada en config\bandanv_update_state.json.
- Esa misma Release no se vuelve a ofrecer automáticamente.
- BUSCAR ACTUALIZACIONES informa que fue omitida tras un rollback.
- Una Release posterior vuelve a ofrecerse normalmente.

TEMPORALES
- Las descargas se preparan en %TEMP%\BandaNV\update-*.
- CANCELAR interrumpe la descarga sin modificar la instalación.
- Después de una actualización exitosa o rollback exitoso se limpia el workspace completo.
- La carpeta general %TEMP%\BandaNV puede permanecer vacía.

ESTRUCTURA PORTABLE
BandaNV/
- BandaNV.exe
- NVupdate.exe
- LEEME.txt
- config/   (se crea al usar la aplicación)
- logs/     (se crea al usar la aplicación)

GENERAR LOS EXE
Ejecutá desde PowerShell en la carpeta del proyecto:

powershell.exe -ExecutionPolicy Bypass -File ".\Build_EXE.ps1"

El comando genera:
- BandaNV.exe
- NVupdate.exe

GENERAR LOS PAQUETES DE RELEASE
Después de compilar:

powershell.exe -ExecutionPolicy Bypass -File ".\Package_Release.ps1"

Se generan dentro de dist\:
- BandaNV_v1.0_Portable.zip
- BandaNV_v1.0_AutoUpdate.zip

HARDENING VALIDADO
- Actualización end-to-end desde GitHub.
- Verificación SHA-256 y rechazo de archivo alterado.
- Rechazo de paquete sin BandaNV.exe.
- Rechazo de ZIP corrupto.
- Protección ante NVupdate.exe ausente.
- Cancelación de descarga.
- Rollback automático.
- Supresión de loop tras rollback.
- Limpieza de temporales tras cancelación y actualización exitosa.
