BandaNV v1.0 RC1.9

RC1.9 — BandaNV Updater / Phase 2A: NVupdate + rollback foundation

NOVEDAD PRINCIPAL
- Se incorpora NVupdate.exe como ejecutable auxiliar permanente de BandaNV.
- NVupdate espera el cierre completo de BandaNV antes de reemplazar el programa.
- Antes de instalar una versión nueva crea un backup del ejecutable actual.
- El backup se conserva hasta que la nueva BandaNV confirma que abrió correctamente.
- Si la nueva versión no confirma el arranque, NVupdate intenta restaurar automáticamente la versión anterior.

HANDSHAKE DE ARRANQUE
- NVupdate inicia la nueva BandaNV con un token único.
- BandaNV confirma el token recién cuando la ventana principal llegó a mostrarse.
- Solo después de esa confirmación el backup puede eliminarse.
- Si la confirmación no llega dentro del tiempo esperado, se activa rollback.

ESTRUCTURA PORTABLE
BandaNV/
- BandaNV.exe
- NVupdate.exe
- LEEME.txt
- config/
- logs/

PAQUETES DE RELEASE
- BandaNV_vX.Y_Portable.zip: descarga manual / instalación nueva.
- BandaNV_vX.Y_AutoUpdate.zip: paquete exclusivo para el actualizador automático.

SEGURIDAD
- config\ y logs\ nunca forman parte del reemplazo.
- La instalación actual no se toca hasta que BandaNV haya descargado y verificado el paquete.
- El rollback restaura BandaNV.exe desde el backup si la nueva build no logra arrancar correctamente.

ESTADO DE PHASE 2
- Phase 2A implementa NVupdate, backup, handshake y rollback.
- La siguiente etapa conecta ACTUALIZAR con descarga real de *_AutoUpdate.zip y verificación SHA-256 desde GitHub Releases.

GENERAR LOS EXE
Ejecutá desde PowerShell en la carpeta de BandaNV:

powershell.exe -ExecutionPolicy Bypass -File ".\Build_EXE.ps1"

El mismo comando genera:
- BandaNV.exe
- NVupdate.exe
