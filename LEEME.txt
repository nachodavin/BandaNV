BandaNV v1.0 RC1.9

RC1.9 — BandaNV Updater / Phase 1: Update Checker

NOVEDAD PRINCIPAL
- GitHub Releases pasa a ser la única fuente oficial de actualizaciones.
- BandaNV consulta el repositorio oficial nachodavin/BandaNV.
- Las builds RC pueden detectar Releases normales y Pre-releases.
- Las versiones estables consultarán únicamente la Latest Release estable.
- Se comparan versiones sin depender de un version.json externo.

CONFIGURACIÓN
- Nuevo bloque ACTUALIZACIONES.
- Muestra la versión instalada.
- Opción "Buscar actualizaciones al iniciar", activada por defecto.
- Botón "BUSCAR ACTUALIZACIONES" para comprobación manual.
- Configuraciones antiguas se migran sin perder origen, categorías ni historial.

COMPROBACIÓN AL INICIAR
- La consulta se ejecuta en segundo plano.
- Si no hay una versión nueva, BandaNV no interrumpe al usuario.
- Si GitHub no responde, el inicio continúa normalmente.
- Si existe una versión superior, aparece el aviso de nueva versión.

PHASE 1
- Esta versión DETECTA actualizaciones y valida la interfaz.
- Todavía NO descarga ni reemplaza BandaNV.exe.
- El botón ACTUALIZAR informa que la instalación automática llegará en la siguiente fase.
- La futura Phase 2 incorporará descarga, verificación SHA-256, updater externo y rollback.

FUENTE OFICIAL
GitHub:
https://github.com/nachodavin/BandaNV

PORTABILIDAD
- BandaNV continúa siendo portable.
- config\ y logs\ permanecen junto al ejecutable.
- El sistema de actualizaciones no modifica esos datos en esta fase.

GENERAR EL EXE
Ejecutá desde PowerShell en la carpeta de BandaNV:

powershell.exe -ExecutionPolicy Bypass -File ".\Build_EXE.ps1"
